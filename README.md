# **Super Panda (Phaser Game)**

**Super Panda** is a 2D platform game developed using **Phaser 3** for a Multimedia Technologies project.  
Guide the panda through different levels, avoid hazards, collect items, and reach the exit door to win.

---

## **Installation**

No installation is required.  
Simply open the project folder in **Visual Studio Code**.

---

## **Usage**

To run the game:

1. Open the project in **VS Code**.  
2. Install the **Live Server** extension (if not already installed).  
3. Click the **“Go Live”** button in the bottom-right corner of VS Code.

Your browser will automatically open the game at:

http://127.0.0.1:5501/



> Any modern browser that supports Phaser 3 is compatible.

---

## **Project Structure**

- **Assets/** – Images, sprites, music, and sound effects  
- **Cenas/** – Game scenes (menu, levels, settings, game over, etc.)  
- **index.html** – Entry point of the game  
- **jogo.js** – Main Phaser setup and scene configuration
